# Алгоритм A*: Машина, обходящая препятствия

Этот проект демонстрирует работу алгоритма A* на примере управления движением виртуальной машины, которая ищет кратчайший путь к цели, избегая столкновений с препятствиями.

## 🚗 Описание

Программа использует алгоритм A* для поиска оптимального маршрута в сетке. Машина движется к цели, обходя статичные и движущиеся препятствия. Алгоритм пересчитывает маршрут в реальном времени при изменении положения препятствий.

**Особенности:**
- Движущиеся препятствия с разной скоростью.
- Реализация A* для поиска пути в двумерной сетке.
- Визуализация пути, препятствий и цели.

## 🛠 Установка

1. Убедитесь, что у вас установлен Python 3.8+.
2. Установите библиотеку `pygame`:
    ```bash
    pip install pygame
    ```
3. Скачайте или клонируйте репозиторий:
    ```bash
    git clone https://github.com/aletonfdg/algorithm-A-python.git
    ```
4. Запустите программу:
    ```bash
    python main.py
    ```
